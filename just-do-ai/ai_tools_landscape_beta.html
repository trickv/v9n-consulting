Orchestrators & Multi-Agent
Orchestrators & Multi-Agent Tools
"One agent is productive — a fleet of them is a different game"
Best for: Engineers who already live in a single-agent CLI and want to run many in parallel, or hand off whole tickets
Single-agent coders like Claude Code are productive; the next leap is running fleets of them. These tools sit above single-agent coders — orchestrating parallel work, polling issue trackers, or going fully autonomous from spec to app. Organized along the Yegge 8-stage AI coding maturity model: stages 3–4 you direct multiple agents hands-on; 5–6 they work autonomously on scoped tickets; 7–8 is autonomous orchestration and the "Dark Factory." This category didn't exist 12 months ago and will consolidate fast — start with the OSS options before paying for anything.
Stages 3–4 You orchestrate; agents work in parallel
Conductor Proprietary
Polished Mac desktop app for running parallel Claude Code + Codex agents in isolated git worktrees with a central dashboard. Apple Silicon only.
Emdash OSS · Apache-2.0
Cross-platform open-source agent dev environment supporting ~24 CLI agents (Claude Code, Codex, Gemini, OpenCode, Amp) with Linear/Jira/GitHub ticket integration, local or SSH remote.
Vibe Kanban OSS · community
Kanban board for agent tasks with isolated worktrees and multi-agent support. Original company Bloop shut down early 2026; project continues as community OSS — easy to try via npx vibe-kanban and worth watching where it goes.
Stages 5–6 Issue-tracker-driven; agents autonomous on scoped work
Symphony OSS · OpenAI
Polls Linear and spawns a Codex session per issue, governed by an in-repo WORKFLOW.md policy file. 13K stars in three weeks.
Composio AO OSS · MIT
Multiple agents in worktrees with full PR-level autonomy — agents fix CI failures and respond to review comments without per-edit human approval.
Stage 7 Autonomous orchestration; many agents, role-based
Gas Town OSS · Steve Yegge
Go-based orchestration running 20–30 parallel Claude Code agents via tmux across 7 worker roles, paired with the Beads work-tracking primitive. Heavy sessions can run $100–200/hr in API costs.
Ralph OSS · contrarian
Proof that simple wins: a bash loop that re-feeds Claude a prompt file. A YC hackathon team produced 1,100+ commits across 6 repos overnight for ~$800 — you don't need fancy machinery for a lot of this.
AgentHub OSS · Karpathy
Agent-native version control: branchless DAG plus message board, designed for swarms coordinating asynchronously. Replaces GitHub's human-centric model.
Stage 8 Dark Factory — spec in, app out
Blitzy Proprietary
Spec-to-app autonomous product — the canonical "Dark Factory" example. Buy, don't build.
Genie (Cosine) Proprietary
Air-gapped enterprise deployment with the highest benchmark scores (72% SWE-Lancer). Compliance-friendly autonomous agent for regulated environments.
These categories aren't walls — tools are converging fast. The best AI-assisted developers reach for different tools at different moments.
This bootcamp focuses on Claude Code because understanding the terminal agent paradigm gives you the deepest foundation. Everything else is a layer of abstraction on top.
